# Survey Feedback Analyzer

## Project Overview

This project is a Python-based Survey Feedback Analyzer developed as part of my Python Module-End Assignment.

The project focuses on collecting survey feedback, cleaning text data, counting specific words, and extracting useful insights from customer feedback.

## Project Objectives

- Store survey feedback using a dictionary of lists.
- Collect additional feedback from users.
- Clean feedback text by removing punctuation and extra spaces.
- Convert feedback into lowercase.
- Count feedback entries containing specific words.
- Calculate the average rating.
- Identify the feedback with the longest comment.
- Find unique words used across all feedback entries.
